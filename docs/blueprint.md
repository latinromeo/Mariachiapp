# **App Name**: Mariachi app

## Core Features:

- Calendar View: Interactive calendar displaying events and rehearsals.
- Dashboard Summary: Dashboard providing a summary of revenue, pending events, and upcoming shows.
- Event Management: Create, edit, and delete events with comprehensive fields.
- Rehearsal Management: Manage rehearsal schedules and details.
- Virtual Assistant: Tool for assisting in creating events with suggestions, and reminders based on past data and user input.
- Multimedia Management: Upload and view multimedia files associated with each event.
- Repertoire System: Categorized song library with song tagging for theme and occasion.

## Style Guidelines:

- Primary color: Vibrant magenta (#FF69B4) to reflect the lively and passionate nature of mariachi music.
- Background color: Light pink (#F9E4EE), a desaturated shade of magenta, providing a gentle and calming backdrop.
- Accent color: Deep red (#B4164F), an analogous color to magenta, offering a bold contrast for interactive elements.
- Body text: 'Inter', a sans-serif font known for its modern, objective look and legibility.
- Headline font: 'Playfair', a modern serif font, adding a touch of elegance and sophistication to titles.
- Use custom icons that reflect the mariachi theme and are consistent with the app's overall style.
- Implement a responsive, mobile-friendly layout with clear sections and intuitive navigation.
